# VidStudio AI — Viral Video Production Studio

Plataforma integral de producción de video faceless y automatización viral diseñada para **La Mente Observadora** y canales de alto rendimiento.

## 🚀 Capacidades
- **1. Radar de Outliers 24/7**: Descubrimiento de anomalías virales con algoritmo VPH en canales de YouTube y exploración de nichos en 1-clic.
- **2. Deconstrucción 1 a 1**: Análisis de guiones competidores, ganchos viscerales y visual DNA.
- **3. Taller de Guiones & AVD**: Generación de guiones en estructura de 4 fases (8-10 min) con audio dual 48kHz (Alonso 🇪🇸 / Andrew 🇺🇸 High-RPM).
- **4. CTR Lab**: Diseño de miniaturas de alto contraste y tests de títulos.
- **5. Copiloto Creativo & Estratégico**: Asistente conversacional interactivo para debatir ángulos psicológicos y transferir ideas al taller en 1-clic.
- **6. Clipper 9:16 Real**: Recorte vertical físico en MP4 con True 9:16 Full Screen, detección facial IA con OpenCV, Split-Screen dual y subtítulos palabra por palabra.
- **7. Tablero de Embudo**: Gestión de producción audiovisual estilo Kanban.
- **8. Incubadora de Canales**: Brand holding para gestionar múltiples arquetipos y personalidades de canal.

## 🛠️ Instalación y Ejecución Local
```bash
git clone https://github.com/isapromord-eng/vidstudio-ai.git
cd vidstudio-ai
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8585
```
Abre tu navegador en `http://localhost:8585`.
